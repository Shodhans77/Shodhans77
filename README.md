> A browser-based, real-time sign language to text translator powered by computer vision. No extra hardware required -- just your webcam.

**Stack:**

```
Python  |  OpenCV  |  MediaPipe  |  TensorFlow  |  Streamlit
```

**Highlights:**
- Live webcam feed with hand landmark detection
- Gesture classification to text output in real-time
- Deployed and accessible from any browser via Streamlit Cloud
- Zero hardware dependency beyond a standard webcam
